# CRUMPLE ZONE — симулятор мягкой физики в браузере

Оригинальная 3D-игра в жанре автомобильного симулятора, вдохновлённая идеей soft-body физики (node-beam).
Каждая машина — это решётка из узлов с массой и «балок»-пружин, которые упруго гнутся, пластически
деформируются (остаточная вмятина) и рвутся. Кузов, стёкла, фары, двери, капот, бамперы и колёса реагируют
на удары по-настоящему, а не по заранее нарисованным анимациям.

Все модели, текстуры и звуки генерируются процедурно в коде — внешних ассетов нет.

## Запуск

Готовая сборка уже лежит в `dist/game.js`, поэтому достаточно открыть `index.html`:

* просто двойным щелчком (работает и с `file://`), или
* через любой статический сервер: `npm run serve` → http://localhost:8080

Сборка из исходников:

```bash
npm install
npm run build        # dist/game.js (минифицированный бандл, esbuild)
npm run dev          # пересборка при изменениях
npm test             # headless-тест физики (Node.js)
```

Нужен браузер с WebGL2 (Chrome, Edge, Firefox, Safari последних версий). Звук включается после первого
клика/нажатия клавиши (требование браузеров).

## Возможности

**Физика (своя, без сторонних движков)**
* XPBD (extended position based dynamics) с шагом 1 мс (1000 Гц) — устойчиво даже при ударах на 130 км/ч.
* Узлы + балки с жёсткостью, демпфированием, пластической текучестью (остаточная деформация) и разрывом.
* Зоны деформации: мягкие передняя/задняя части, жёсткий салон, прочные лонжероны, крыша.
* Подвеска (пружина, прогрессивный амортизатор, отбойник, стабилизаторы), шины по модели «magic formula»
  с эллипсом трения, зависимостью от нагрузки и покрытия (асфальт, бетон, грунт, трава, песок, грязь, снег).
* Двигатель с кривой момента, турбонаддувом, сцеплением; автомат и механика; FWD/RWD/AWD; ABS и антипробуксовка.
* Повреждения влияют на поведение: смещённые точки крепления дают развал/схождение, мотор теряет мощность
  и глохнет, колёса отрываются, двери/капот/багажник распахиваются и отлетают, стёкла трескаются и бьются.
* Столкновения машина-машина, машины с реквизитом (конусы, бочки, ящики, кегли, блоки), деревья и фонари
  ломаются и падают. Вода: машина держится на плаву, набирает воду и тонет, двигатель ловит гидроудар.
* Электронные помощники: ABS, распределение тормозных усилий по нагрузке оси, антипробуксовка со стабилизацией
  (сбрасывает газ при заносе) — отключаются клавишами X/G для дрифта.

**Автомобили** (8 оригинальных моделей): седан, хэтчбек, спорткар, внедорожник, пикап, фургон-грузовик,
автобус и полицейский перехватчик. Гараж: цвет (палитра + любой), двигатель (включая электромотор),
коробка, привод, подвеска (комфорт/стандарт/спорт/лифт), шины, диски, размер колёс, ABS/TCS.

**Открытый мир 2×2 км**: город Новоград, кольцевая трасса, гоночная трасса «Кольцо Ветров», горный
серпантин, лес, озеро, карьер для бездорожья, аэродром с ВПП и полигон для краш-тестов
(стены, столб, трамплины, рампа для опрокидывания, мёртвая петля, штабеля ящиков и бочек).
День/закат/ночь (фары, фонари, светящиеся окна).

**Режимы**: свободная езда (с трафиком ИИ), краш-тест (12 сценариев с отчётом: скорость удара, пиковая
перегрузка, глубина деформации), гонка против ИИ, испытания на время (4 трассы, рекорды сохраняются),
погоня (уйти от полиции / задержать нарушителя), песочница (спавн машин с разным поведением ИИ и объектов,
гравитация, замедление времени), редактор сцен.

**Редактор**: трамплины, кикеры, посадочные горки, блоки, стены, столбы, платформы, «лежачие полицейские»,
четверть-трубы, мёртвые петли, стены из шин, подвижные объекты и точка старта. Перемещение, поворот, высота,
параметры, материал; сохранение сцен в браузере, экспорт/импорт JSON, тест-драйв.

**Графика и звук**: тени, тональная компрессия, отражения окружения на лаке, процедурное небо, туман,
частицы (дым шин, пыль, искры, осколки стекла, дым из мотора, брызги), следы шин. Звук полностью синтезирован:
двигатели (I3/I4/V6/V8/дизели/электро) по оборотам и нагрузке, турбина и blow-off, визг шин, гравий,
ветер, скрежет металла, удары, бьющееся стекло, сигнал, сирена.

## Управление

| Клавиша | Действие |
|---|---|
| W / ↑ | Газ |
| S / ↓ | Тормоз, при остановке — задний ход |
| A D / ← → | Руль |
| Пробел | Ручник |
| R | Починить и поставить на колёса |
| T | Вернуть на старт режима |
| C | Камера (сзади, дальняя, капот, салон, орбита, кино) |
| ЛКМ + мышь, колесо | Обзор камерой, зум |
| Q / E | Передача вниз / вверх (переключает на механику) |
| M | Автомат ↔ механика |
| O / U / K | Двери / капот / багажник |
| J | Замедление времени |
| H, L, N, Z | Сигнал, фары, сирена (полиция), аварийка |
| X / G | ABS / антипробуксовка |
| B | Карта и телепорт (свободная езда, песочница) |
| V | Свободная камера |
| Tab | Пересесть в другую машину (песочница) |
| Esc / P | Пауза |
| F1 / F2 | Подсказка по управлению / FPS |

**Геймпад** (стандартная раскладка): RT — газ, LT — тормоз, левый стик — руль, A — ручник, Y — ремонт,
B — на старт, LB/RB — передачи, X — сигнал, Back — камера, Start — пауза, правый стик — обзор.

## Архитектура

```
src/
  core/        математика, ввод (клавиатура/геймпад), камеры
  physics/     softbody.js (XPBD узлы/балки), world.js (подшаги, контакты, сон), statics.js, terrain.js
  vehicle/     defs.js (каталог), shape.js (параметрический кузов), lattice.js (решётка узлов),
               vehicle.js (подвеска, шины, трансмиссия, повреждения), carmesh.js / carvisual.js (меш, скиннинг)
  world/       mapgen.js (генерация мира), worldvisual.js, sky.js, dynamics.js (реквизит/обломки), textures.js
  fx/          частицы, следы шин
  audio/       процедурный синтез звука
  ai/          ИИ-водители (траектория с планированием скорости, преследование)
  modes/       игровые режимы
  editor/      редактор сцен
  ui/          HUD, меню, карта
test/          headless-тесты физики и Playwright-скрипты
```

Визуальная модель автомобиля строится из того же параметрического описания, что и физическая решётка;
каждая вершина меша «привязана» к 4 ближайшим узлам, поэтому меш деформируется вместе с физикой.
Детали (двери, капот, бамперы, стёкла, фары) оценивают своё повреждение по пластическому удлинению
окружающих балок и при превышении порогов отщёлкиваются, болтаются на петлях или отрываются
и становятся отдельными мягкими телами.

## Производительность

Физика одного легкового авто — около 3% одного ядра. Машины трафика вдали от камеры переключаются на
упрощённое движение по маршруту и возвращаются к полной soft-body симуляции при приближении.
Если FPS низкий: «Настройки» → качество «Низкое»/«Среднее» и масштаб разрешения 75%, уменьшите трафик.

## Тесты

* `npm test` — разгон, поворот и торможение в headless-режиме;
* `node test/crash.mjs sedan 50,80 wall` — краш-тест (глубина деформации, пиковая перегрузка);
* `node test/drive.mjs` — разгон/максималка/слалом всех машин; `node test/jump.mjs` — падения с высоты;
* `test/play.mjs` — сценарии в браузере через Playwright (скриншоты режимов).
